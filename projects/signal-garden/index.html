Can a picture survive a scratch in its signal?

Send the same picture two ways. Add the same burst of flipped bits. Predict which picture comes back whole.

1. Plant a picture

Tab to a tile; Enter or Space flips it. 1 = ink, 0 = paper.

Each four-pixel row becomes a seven-bit Hamming block: four picture bits and three parity bits.

Same budget: 16 picture bits → 28 channel bits in each layout. Interleaving changes their order, adding no extra bits.

One burst per picture, no wrapping. Changing any input starts a fresh prediction.

2. Make a prediction

A block can correct one flipped bit. Sending rows consecutively can put a burst inside one block. Interleaving sends one bit from each row in turn.

Choose a prediction to begin. Nothing advances by itself.

Paused · advance at your own pace

The edge of the lesson

    
Depth-four interleaving spreads any one burst of at most four flipped bits across
      four blocks, with at most one error in each. Five can put two errors in a block.
      Try five bits starting at position 1 after your first run.

    
This seven-bit decoder attempts a single-bit correction. With multiple errors,
      it can confidently produce wrong pixels. It has no overall parity bit and
      cannot reliably distinguish a single error from multiple errors. “Matches”
      uses the simulator’s original picture, which a real receiver does not know.

    
We compare one fixed burst on two layouts, not real-world channel performance.
      No animation, score, timer, account, storage or network request is needed.
