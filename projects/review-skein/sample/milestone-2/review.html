Added. 1# Read the review comments
Added. 2
Added. 3The comment viewer turns the packet's `comments.json` into readable terminal
Added. 4output or a standalone offline HTML page. It uses Skein's existing strict
Added. 5version-2 comment reader. It shows IDs, bodies, full commit/path/side/line anchors
Added. 6and their source text, open/resolved status, orphan reasons and rebase history.
Added. 7It reads the comments file only, does not change the packet, and needs neither
Added. 8Git nor a bundle to display those comments.
Added. 9
Added. 10```sh
Added. 11python3 projects/review-skein/comments_view.py /path/to/packet/comments.json
Added. 12python3 projects/review-skein/comments_view.py /path/to/packet/comments.json \
Added. 13 --resolution open --state orphan
Added. 14```
Added. 15
Added. 16Both filters default to `all`. Resolution is `open` or `resolved`; anchor state
Added. 17is `anchored` or `orphan`. Filters combine: the example shows only open orphans.
Added. 18The first lines report shown/total counts, the selected filters, and totals for
Added. 19the entire file, so an empty result does not imply that the packet has no comments.
Added. 20Comments retain their stored order; nothing is reanchored, resolved or edited.
Added. 21Terminal and HTML output display control/direction characters as literal Unicode
Added. 22escapes, preserving ordinary Unicode prose, newlines and tabs.
Added. 23
Added. 24For a page you can carry to a browser:
Added. 25
Added. 26```sh
Added. 27python3 projects/review-skein/comments_view.py /path/to/packet/comments.json \
Added. 28 --format html > /path/to/comments-review.html
Added. 29```
Added. 30
Added. 31Choose a separate output file: shell redirection truncates an existing target,
Added. 32so never redirect over `comments.json` or another packet member. The viewer itself
Added. 33only writes to standard output. Open the result as a local file in a browser;
Added. 34it has a comments index, skip link, headings, textual status, wrapped text and
Added. 35visible link focus. All user text is escaped. It contains no scripts, external
Added. 36resources or network links, and its CSP denies external resources. It is a
Added. 37snapshot: regenerate it after using `skein.py edit-comment`, `resolve-comment`
Added. 38or `reopen-comment`. Existing `review.html` remains the code diff.
Added. 39
Added. 40A version-1 comments file fails with the existing `migrate-comments PACKET`
Added. 41instruction. Migration is a separate deliberate action through `skein.py`;
Added. 42the viewer never silently upgrades data. Invalid UTF-8, malformed JSON,
Added. 43duplicate keys/IDs, invalid comments, missing/symlink inputs and inputs larger
Added. 44than Skein's 32 MiB JSON limit fail with exit 1 and no rendered output. Invalid
Added. 45CLI arguments exit 2; successful output exits 0. Every record is validated
Added. 46before applying filters, so filtering cannot hide malformed comments.
Added. 47
Added. 48This view reports what the comments file says. It does not authenticate authors,
Added. 49verify the Git bundle or check that an anchor still exists in the diff. An orphan
Added. 50remains visibly orphaned. The original file and comments model remain the record;
Added. 51HTML is derived output. Markup and CLI tests do not establish browser rendering
Added. 52or screen-reader speech. The non-author phone/desktop and screen-reader try
