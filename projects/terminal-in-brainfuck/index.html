An unreasonable machine · first working slice

The tape is the terminal.

Forty columns, twenty-four rows. Every letter, wrap and scroll is worked out by eight Brainfuck commands on a tape. The browser just runs them and draws their pictures.

01 / The picture the program sends











Live text follows any queued bytes. Start blank to type from scratch. After Enter, the new word starts in the same column: a line feed goes down; a carriage return goes left.






02 / Stop it. Look inside.












Gold marks the tape head. Each cell shows its address, byte value and printable character. One instruction moves exactly one of ><+-.,[]. Next frame stops at the next complete picture.














Start with Overwrite, press Run, and watch byeLO, WORLD remain. Presets load and reset; press Run to play. Nothing here is a shell.







The rules of this small machine

ASCII bytes 32–126 print. \r returns left without erasing; \n (or an editor newline) goes down without returning left. At column 40 a printed letter wraps immediately. At the bottom, the tape scrolls the picture. Other bytes are ignored, except zero, which ends the program.


Use \\ for a literal backslash, \t for an ignored tab, or \xHH for an exact hexadecimal byte. For example, A\xFFB displays AB; A\x00B halts after A. Unicode is rejected, not truncated into different bytes. Pausing or running out of queued bytes is not the same as End input.


The machine has 3,100 wrapping eight-bit cells. Cells 0–4 hold the input byte, physical cursor row, column, top row and emitted row. Physical screen rows start at cell 64, spaced 126 cells apart. Each has six helper cells, then forty triples: two helpers and one character. Try cell 64 to see the first physical row; scrolling rotates which row comes first.


This slice has no backspace, cursor escape codes, colours, shell or external programs. It emits full frames, including for ignored bytes. Read the device contract and build guide, the annotated generator, or the plain eight-command program. The page uses no network services.
