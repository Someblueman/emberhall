A real shell · compiled to Brainfuck from Python

The tape is the terminal.

A shell runs on a real pseudo-terminal. Its output passes through an eight-command program that keeps every letter, cursor, scroll and colour on its tape. That program is compiled from annotated Python, not handwritten Brainfuck.

Run the real terminal

From a clone of the public repository, run this at its root:

python3 projects/terminal-in-brainfuck/run_terminal.py

macOS or Linux · Python 3.10+ · Node 18+ · system ps. Use an ANSI truecolour terminal at least 40 columns wide and 24 rows high. No project packages to install.

Type printf 'hello\n' and press Enter. Type exit or press Ctrl-] to leave. This is a real /bin/sh with your launching process’s file access.

Fixed at 40 × 24, ASCII and a small cursor/erase/colour subset; visibly slower than an ordinary terminal. The recorded native checks ran on macOS. Linux remains unverified.

The rules of this small machine

ASCII bytes 32–126 print. \r returns left without erasing; \n (or an editor newline) goes down without returning left. At column 40 a printed letter wraps immediately. At the bottom, the tape scrolls the picture. Backspace moves left without erasing; tab goes to the next eight-column stop. Zero ends the program.


Use \\ for a literal backslash, \t for a tab, or \xHH for an exact hexadecimal byte. For example, A\xFFB displays AB; A\x00B halts after A. Unicode is rejected, not truncated into different bytes. Pausing or running out of queued bytes is not the same as End input.


The machine has 6,000 wrapping eight-bit cells. Cells 0–4 hold the input byte, physical cursor row, column, top row and emitted row. Physical screen rows start at cell 64, spaced 246 cells apart. Each has six helper cells, then forty pairs of triples: a character and its colour, each with two helpers. The stored colour is one more than its emitted value, so black-on-black remains data. Try cell 64 to see the first physical row; scrolling rotates which row comes first.


Try Move without erasing: ABCDE becomes ABC!E. Erase a line tail keeps AB on the second row and leaves the cursor in its third column. CSI cursor and erase sequences now run on the tape; see the exact control rules. Try Coloured ink to select ink with \x1b[31m, or paper with \x1b[37;44m. Erasure uses the current colour, and scroll carries each letter’s ink with it. The colour rules accept at most two parameters. No live OS shell runs inside this browser page. It emits full frames, including for ignored bytes. Read the device contract and build guide, the annotated Python compiler, or the eight-command program compiled to Brainfuck from Python.
