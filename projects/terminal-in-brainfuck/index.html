An unreasonable machine · colour on the tape

The tape is the terminal.

Forty columns, twenty-four rows. Every letter, wrap and scroll is worked out by eight Brainfuck commands on a tape. The browser just runs them and draws their pictures.

01 / The picture the program sends











Enter sends a line feed. Backspace moves left so your next letter can overwrite the old one.


Live text follows any queued bytes. Start blank to type from scratch. After Enter, the new word starts in the same column: a line feed goes down; a carriage return goes left.






02 / Stop it. Look inside.












Gold marks the tape head. Each cell shows its address, byte value and printable character. One instruction moves exactly one of ><+-.,[]. Next frame stops at the next complete picture.



















Start with Overwrite, press Run, and watch byeLO, WORLD remain. Presets load and reset; press Run to play. Nothing here is a shell.

The rules of this small machine

ASCII bytes 32–126 print. \r returns left without erasing; \n (or an editor newline) goes down without returning left. At column 40 a printed letter wraps immediately. At the bottom, the tape scrolls the picture. Backspace moves left without erasing; tab goes to the next eight-column stop. Zero ends the program.


Use \\ for a literal backslash, \t for a tab, or \xHH for an exact hexadecimal byte. For example, A\xFFB displays AB; A\x00B halts after A. Unicode is rejected, not truncated into different bytes. Pausing or running out of queued bytes is not the same as End input.


The machine has 6,000 wrapping eight-bit cells. Cells 0–4 hold the input byte, physical cursor row, column, top row and emitted row. Physical screen rows start at cell 64, spaced 246 cells apart. Each has six helper cells, then forty pairs of triples: a character and its colour, each with two helpers. The stored colour is one more than its emitted value, so black-on-black remains data. Try cell 64 to see the first physical row; scrolling rotates which row comes first.


Try Move without erasing: ABCDE becomes ABC!E. Erase a line tail keeps AB on the second row and leaves the cursor in its third column. CSI cursor and erase sequences now run on the tape; see the exact control rules. Try Coloured ink to select ink with \x1b[31m, or paper with \x1b[37;44m. Erasure uses the current colour, and scroll carries each letter’s ink with it. The colour rules accept at most two parameters. A shell and external programs remain outside this machine. It emits full frames, including for ignored bytes. Read the device contract and build guide, the annotated generator, or the plain eight-command program. The page uses no network services.
