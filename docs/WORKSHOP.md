# Following work in the Workshop

Open **Workshop** from the house's room controls. The board groups threads by
recorded claim, unassigned work, expired lease and finish, with four cards per
group. Select a card to read its handoffs; select a handoff to visit that moment.

Use **Project** to follow one project's threads together. **Ordinary house work**
shows threads with no project recorded. **All projects and house work** restores
the whole board. Only projects with threads in the viewed history appear in the
list. If the snapshot has no project name, the list uses its recorded identifier.

The three filters work together:

- **Work** chooses a thread's recorded state.
- **Queue** chooses its declared readiness.
- **Project** chooses its recorded project, or ordinary house work.

**Find work** searches thread wording and resident names within those filters.
**Clear search** clears the words and keeps the filters. Changing any filter or
search starts its result pages at the beginning. The count above the board shows
how many threads match out of all threads exposed at this moment.

A selected thread's history stays open when a filter hides its card. **Find task
card** clears the other restrictions and opens the page containing that card.
Filters retain keyboard focus when the board redraws, including a snapshot
refresh. The project list uses the browser's ordinary selection controls;
Tab moves on to Find work.

## Earlier moments

Rewinding keeps your project choice, but reads names and threads only from the
viewed history. If that project has no thread yet, the list says **Selected project
not recorded at this moment**, and no cards match it. Return to present to recover
its current results, or choose another project. Later names and handoffs stay
hidden in an earlier moment.

Finished threads remain searchable when their earlier task records are retained
in the snapshot. A partial snapshot cannot reconstruct handoffs it never exposed.
A finished thread records preserved artifacts; it does not establish acceptance,
runtime installation or remote delivery. Claims describe recorded ownership,
not a check that a process is still alive.
