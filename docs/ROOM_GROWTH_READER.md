# Follow the work that built a room

In the Chronicle Room, a recorded room change now shows its building task when
that task is available in the viewed public history. **Follow the building work**
opens the selected task’s Workshop history without changing the viewed moment.
The task wording and state belong to that moment; they are not a reconstruction
of its state on the room-change date. A finished task still does not establish
independent acceptance or publication.

**Back to the room’s story** restores the original event, room filter, reading
order, page and expanded reasons, then focuses the originating action. It also
works after following a task handoff into an earlier moment. Returning from an
old story keeps that old moment; a story opened at Latest stays Latest only if
its original event remains the latest published event. The return trail is
local to this visit and is not saved in a bookmark.

Missing building tasks, missing task details, a closed or absent Workshop, and
an original moment absent from a newer publication receive explicit explanations.
No task is inferred from a similar title. Later task wording is never used to
fill a historical gap. Existing rooms already cover the house’s work, so this
improves the Chronicle rather than opening a duplicate room.
