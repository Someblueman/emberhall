## Bounded calculation, not independent acceptance

Locally written Python, no downloaded code or dependencies. Standardize each
selected subsequence, rotate its maximum to the front, and count the resulting
(k−1)! possible classes. Fixing the host's maximum first loses nothing because
rotating the host preserves circular containment. No inverse-permutation
symmetry or arbitrary value relabeling was used.

* For k=5, all 5,040 eight-entry circles were examined. The maximum coverage
  was 22 of 24 classes, attained for example by `(8,1,4,6,2,7,5,3)`.
  The published `(2,5,8,3,1,4,7,9,6)` covers all 24. This calculation therefore
  gives length nine, pending independent reconstruction and prior-work check:
  any shorter successful host could be extended to length eight without
  destroying its existing patterns.
* For k=6, all 362,880 ten-entry circles were examined. The maximum coverage
  was 88 of 120, attained by `(10,2,5,8,1,7,3,9,6,4)`.
  The elapsed time printed by that exploratory run was 22.655 seconds.
* A separate seeded sample of 1,000 permutations at each of lengths 11, 12
  and 13 found maximum coverages 104, 117 and 120. There were 0, 0 and 3
  complete samples respectively. One complete thirteen-entry witness was
  `(2,13,6,5,12,3,7,9,11,4,10,1,8)`.
  Sampling does not exclude eleven or twelve. The supported interval is
  11 ≤ L_circ(6) ≤ 13, not an exact answer.

Here is the complete exhaustive core and witness check, retained inside this
research note rather than shipped as an unselected tool. It also independently
recounts the stated host witnesses against explicit target classes.

```python
from itertools import combinations, permutations
from math import factorial

def canonical(values):
    ranks = {v: i + 1 for i, v in enumerate(sorted(values))}
    pattern = tuple(ranks[v] for v in values)
    cut = pattern.index(len(values))
    return pattern[cut:] + pattern[:cut]

def coverage(host, k):
    return {canonical(part) for part in combinations(host, k)}

def exhaustive(n, k):
    classes = {(k,) + p: i
               for i, p in enumerate(permutations(range(1, k)))}
    lookup = {p: 1 << classes[canonical(p)]
              for p in permutations(range(1, n + 1), k)}
    subsets = list(combinations(range(n), k))
    best = 0
    checked = 0
    for tail in permutations(range(1, n)):
        host = (n,) + tail
        bits = 0
        for indices in subsets:
            bits |= lookup[tuple(host[i] for i in indices)]
        best = max(best, bits.bit_count())
        checked += 1
    return checked, best

assert exhaustive(8, 5) == (5040, 22)
assert exhaustive(10, 6) == (362880, 88)
assert len(coverage((8, 1, 4, 6, 2, 7, 5, 3), 5)) == 22
assert len(coverage((2, 5, 8, 3, 1, 4, 7, 9, 6), 5)) == factorial(4)
assert len(coverage((10, 2, 5, 8, 1, 7, 3, 9, 6, 4), 6)) == 88
assert len(coverage((2, 13, 6, 5, 12, 3, 7, 9, 11, 4, 10, 1, 8), 6)) == factorial(5)
print("circular screen: five-entry minimum 9; six-entry bounds 11..13")
```
