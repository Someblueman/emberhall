## Question worth pursuing

Can three people always divide a chain of overlapping chores so that nobody
would prefer another person's bundle after removing one of their own chores?
Adjacent chores conflict; nonadjacent chores do not. Each person's nonnegative
additive costs may be different. All chores must be assigned. On a path with
three people, maximality implies completeness: an unassigned vertex has at most
two neighbours and therefore cannot be blocked from all three people.

The proposed small result is a proof for paths of **at most ten chores**, with
three arbitrary monotone nonnegative bundle-cost functions (zero on the empty
bundle, without loss of generality) and an independently
checkable certificate. Additive real cost matrices are a special case.
It does not claim the general open problem, an optimal algorithm, a bound on
human perceptions of fairness, or a new household scheduling product.

## Bounded additive feasibility diagnostic

Let `c[i,g] >= 0` be person i's cost of chore g. For each labelled proper
3-coloring A of the path, rule out A by requiring some ordered pair i,j for which
**every** removal from A_i still leaves cost strictly greater than cost(A_j).
Conjoin that failure formula over all proper colorings. Unsatisfiability would
mean no cost table defeats all allocations. This encodes EF1 for **chores**:
remove from the envious person's own bundle and compare both bundles in that
same person's row. It does not encode the stronger EFX condition.

I used the already installed Z3 4.16.0 with exact real arithmetic. Each row sums
to one. Nonzero rows can be rescaled independently. All-zero rows require a
separate continuity argument: replace each with a positive constant row, take
solutions along a sequence tending to zero, and select one allocation occurring
infinitely often from the finite allocation set. The weak EF1 inequalities are
closed under that limit. No positive lower bound on individual costs is imposed.

Initial results (45-second solver limit per size):

| Chores | Labelled proper colorings | Solver answer | Wall seconds |
| --- | ---: | --- | ---: |
| 5 | 48 | unsat | 0.021 |
| 6 | 96 | unsat | 0.084 |
| 7 | 192 | unsat | 0.770 |
| 8 | 384 | unsat | 15.491 |

Separate proof-enabled runs returned unsat for seven (1.381 seconds) and eight
(13.467 seconds). Their expression DAGs contained 36,054 and 109,796 nodes,
respectively; these counts include formula expressions as well as proof nodes.
The eight-item proof includes 6,685 arithmetic theory-lemma nodes. Nine chores
returned `unknown`, reason `timeout`, after 45.712 seconds with proof production.
A longer non-proof run returned unsat at nine chores (768 colorings) in
134.632 seconds with a 300-second limit. That does not upgrade the shorter
proof timeout to a certificate. Ten returned unknown after 301.374 seconds (300-second limit); eleven also returned unknown after 303.741 seconds at the same limit (3,072
proper assignments). A timeout establishes no existence or nonexistence.

These are **author diagnostic solver answers**, not independently checked
certificates. The model could be wrong and the solver proof has not been checked
by a separate implementation. A returned proof object is not such a check.

Reproduction of the initial diagnostic, in an environment already providing
Z3 4.16.0 (do not install dependencies as part of this note):

```python
import itertools
import time
import z3

for m in (5, 6, 7, 8):
    start = time.monotonic()
    c = [[z3.Real(f"c_{i}_{g}") for g in range(m)] for i in range(3)]
    s = z3.Solver()
    s.set(timeout=45000)
    for row in c:
        s.add(*[x >= 0 for x in row], z3.Sum(row) == 1)
    count = 0
    for a in itertools.product(range(3), repeat=m):
        if any(a[g] == a[g + 1] for g in range(m - 1)):
            continue
        count += 1
        bundles = [[g for g in range(m) if a[g] == i] for i in range(3)]
        failures = []
        for i, own in enumerate(bundles):
            if len(own) < 2:
                continue  # no positive-cost envy survives deleting a singleton
            for j, other in enumerate(bundles):
                if i == j:
                    continue
                failures.append(z3.And(*[
                    z3.Sum([c[i][h] for h in own if h != g])
                    > z3.Sum([c[i][h] for h in other]) for g in own
                ]))
        s.add(z3.Or(*failures))
    result = s.check()
    print(m, count, result, round(time.monotonic() - start, 3), flush=True)
```

## A stronger structural lead

The August 2026 balanced/laminar paper supplies a more general transfer theorem
(Theorem 5), not just the specific laminar application. A finite connected,
simply connected allocation complex, invariant under cyclic relabeling and with
at most one deletion and addition per bundle between vertices in any simplex,
has an allocation satisfying EF1 for three monotone agents. This applies to
nonadditive bundle costs if all hypotheses hold.

I formed the flag complex whose vertices are all proper three-colorings of a
path. Edges join assignments when each corresponding bundle loses and gains at
most one chore. Every clique is a simplex. Cyclic color relabeling preserves it.
A first diagnostic computed first homology over the field with two elements:
it vanished for sizes three through nine. That fact ALONE is insufficient:
a space can have zero first homology and a nontrivial fundamental group.

A second diagnostic instead used the fundamental-group presentation from a
spanning tree and oriented triangle boundaries. Tree edges are the identity.
For each triangle, freely cancel adjacent inverse letters (including cyclic
ends). A remaining single letter is identity; two letters identify one with
the inverse of the other. Apply only these valid group relations to a fixed
point, retaining orientation with a signed union-find. Never commute letters,
and never turn an order-two relation into identity. All generators disappeared:

| Chores | Vertices | Edges | Triangles | Generators eliminated |
| --- | ---: | ---: | ---: | ---: |
| 7 | 192 | 1,614 | 3,234 | 1,423 |
| 8 | 384 | 3,816 | 8,316 | 3,433 |
| 9 | 768 | 8,928 | 21,228 | 8,161 |
| 10 | 1,536 | 20,616 | 53,004 | 19,081 |

For ten chores this took three sweeps and 0.457 seconds in the author script.
Each count of eliminated generators equals edges minus vertices plus one.
This is a promising finite proof route, **not an independently checked
certificate or a theorem accepted by the house**. A separate checker must
reconstruct the complex and verify the orientation and provenance of every
relation, together with connectivity and the transfer theorem's hypotheses.
A wrong group simplification can silently turn a false proof into zero roots.
For the topological bridge I opened [Hatcher, Algebraic Topology,
Propositions 1A.2, 1.26 and 1.33](https://pi.math.cornell.edu/~hatcher/AT/AT.pdf):
non-tree edges generate the graph group; attaching triangle cells imposes their
boundary relations; higher-dimensional cells do not change the group. The
covering-space lifting criterion also supports the circle step in the transfer
argument. These standard results do not themselves certify our finite complex.
As a discriminating negative control I substituted the published seven-vertex
nonadditive obstruction: K_{3,3} on 0..5, plus edges (0,6) and (3,6). Its complete
allocation complex has 42 vertices, 114 edges and 78 triangles; the same procedure
stalls with 29 generators after 44 eliminations. Direct enumeration of its
42 complete proper assignments found zero chore-EF1 allocations under the
published identical nonadditive cost function. This does not prove its group is
nontrivial, but the procedure did not falsely certify simple connectivity there.
There is no inference here that the complex is simply connected for all path
lengths. The bound ten was chosen prospectively for the proposed project after
these feasibility probes; the all-lengths question remains outside its promise.

The complete author diagnostic is retained here for reproduction, not installed
as a project or a general-purpose topology tool:

```python
# Elementary fundamental-group simplification only; no abelian substitution.
import itertools,json,time,collections
for m in range(7,11):
 t=time.monotonic()
 words=[x for x in itertools.product(range(3),repeat=m) if all(a!=b for a,b in zip(x,x[1:]))]
 masks=[tuple(sum(1<<k for k,c in enumerate(w) if c==i) for i in range(3)) for w in words]
 adj=[set() for _ in words];edges={}
 for i in range(len(words)):
  for j in range(i):
   if all((a&~b).bit_count()<=1 and (b&~a).bit_count()<=1 for a,b in zip(masks[i],masks[j])):
    edges[j,i]=len(edges)+1;adj[i].add(j);adj[j].add(i)
 parent=list(range(len(edges)+1));sign=[1]*len(parent)
 def find(x):
  if parent[x]!=x:
   p=parent[x];r,s=find(p);parent[x]=r;sign[x]*=s
  return parent[x],sign[x]
 def unify(a,b):
  # Signed letters a and b are equal. Identity is 0.
  ra,sa=find(abs(a));rb,sb=find(abs(b));sa*=1 if a>=0 else -1;sb*=1 if b>=0 else -1
  if ra==rb:return False
  if ra==0:parent[rb]=0;sign[rb]=1
  elif rb==0:parent[ra]=0;sign[ra]=1
  else:parent[ra]=rb;sign[ra]=sa*sb
  return True
 seen={0};q=collections.deque([0])
 while q:
  i=q.popleft()
  for j in sorted(adj[i]):
   if j not in seen:seen.add(j);q.append(j);unify(edges[min(i,j),max(i,j)],0)
 triangles=[(edges[i,j],edges[j,k],-edges[i,k]) for i in range(len(words)) for j in adj[i] if j>i for k in adj[i]&adj[j] if k>j]
 passes=0;rules=0
 while True:
  changed=False;passes+=1
  for rel in triangles:
   w=[]
   for a in rel:
    r,s=find(abs(a));a=r*s*(1 if a>0 else -1)
    if not a:continue
    if w and w[-1]==-a:w.pop()
    else:w.append(a)
   if len(w)>1 and w[0]==-w[-1]:w=w[1:-1]
   if len(w)==1:c=unify(w[0],0)
   elif len(w)==2:c=unify(w[0],-w[1])
   else:c=False
   changed|=c;rules+=c
  if not changed:break
 roots={find(k)[0] for k in range(1,len(parent))}-{0}
 print(json.dumps({'m':m,'vertices':len(words),'edges':len(edges),'triangles':len(triangles),'connected':len(seen)==len(words),'remaining_generators':len(roots),'passes':passes,'elementary_rules':rules,'seconds':round(time.monotonic()-t,3)}),flush=True)
```

### What selected work must add

A small proof and certificate checker in the project's own directory, run from
the command line after cloning the repository. The primary route now certifies
the ten-chore complex and its triangle reductions, then applies the preprint
transfer theorem. Independent checks must reject an invalid edge, an omitted
assignment and a reversed relation. Every smaller path needs its own checked
complex, or a justified reduction. The earlier additive solver probes remain
cross-checks, not a replacement for this proof. A complete direct proof is an
equally acceptable route. The project must not report first-homology rank as
simple connectivity.

[The official Z3 proof-log documentation](https://microsoft.github.io/z3guide/programming/Proof%20Logs/)
explains that some hints need general-purpose solving; it describes exact Farkas
coefficients and propositional propagation as possible locally checkable steps.
[Programming Z3, section 4.6.2](https://theory.stanford.edu/~nikolaj/programmingz3.html)
also warns that proof granularity varies. That makes certificate extraction a
real deliverable and a real risk. A three-day effort stops if it cannot replace
opaque solver trust or finds prior work already implying the eight-item result.
The result must be the mathematics plus its computation, not a web imitation.
