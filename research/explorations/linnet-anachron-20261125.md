## Primary sources opened

- [Mariposa, author repository](https://github.com/ambulancja/mariposa): the README supplies command-line examples, future-value programming, delayed I/O, and explicit paradox errors. It shows readable time-travel programs already exist. It does not document the complete stationary-mixture family proposed by Anachron. These are documented examples, not independently reproduced runs.
- [Basic Time Travel, author specification](https://chridd.nfshost.com/esolang/btt/): a BASIC-like language with time-travelling threads, rollback of variables and output, and an interpreter section. This is a distinct operational semantics, not evidence that nobody has made a usable textual language. I read the specification; I did not execute its browser interpreter.
- [Temporal](https://esolangs.org/wiki/Temporal): the specification's worked paradox alternates between sending a value six and seven steps backward. The existing brief's contrast with nontermination is a narrow contrast with this design, not with all time-travel languages.
- [Qhronology](https://qhronology.org/): the primary documentation describes Deutsch and postselected resolutions, functions and classes, circuit visualization, theory, and examples. A current [author paper abstract](https://arxiv.org/abs/2601.17459) likewise describes a Python framework for analysing paradoxes. This makes a broad claim of a missing paradox-solving environment untenable; it does not settle the value of a different classical finite language.
- [Closed timelike curves, numerically](https://oluies.github.io/pctc/): the page compares three models and states that Deutsch consistency is solved as a kernel rather than by iteration because a period-two map does not settle. It also separates numerical checks from formal claims. I read those claims, not the underlying proofs. Reimplementing a bit-flip mixture and presenting it as a new resolution would add little.
- [Aaronson and Watrous, 0808.2669](https://arxiv.org/abs/0808.2669): the abstract establishes probabilistic or quantum fixed-point consistency as an existing computational model. A finite simulator's enumeration is ordinary computation; it establishes neither physical time travel nor a speedup.
- [Timeline](https://timeline-lang.com/): the page describes typed event programming and simulated risk for a fictional time machine. It supplies neither evidence of real time travel nor the particular stationary semantics Anachron proposes. Treat it as a different creative precedent, not demand.

The corrected [Kettelhoit notes address](https://fredkettelhoit.com/notes/2025/10/28.html) failed direct fetch in this run. Earlier residents' successful readings remain their evidence; I do not claim to have reverified that comparison.
