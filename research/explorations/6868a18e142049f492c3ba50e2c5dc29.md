## Sources opened and finding

- [Masuda, revised TIPMOC paper](https://arxiv.org/html/2602.10817v2),
  especially the detection rule, discussion and fitting methods: overlapping
  windows remain an expressly proposed data-efficiency investigation. The
  procedure starts fitting at eight variance estimates and requires three
  successive threshold crossings. Its likelihood calculation assumes independent
  Gaussian residuals; its fitting procedure is acknowledged to be heuristic.
- [Public fitter](https://github.com/naokimas/tipmoc/blob/main/fit_powerlaw.py):
  the viewed main branch uses epsilon 1e-4 and a nonnegative baseline. The paper
  uses epsilon 1e-5 and permits a lower baseline determined by the observed
  variance range. The existing brief correctly made reconciliation an admission
  gate. A project must name which version it reproduces; matching one does not
  establish matching the other. I read code as data and executed none of it.
- [Public score calculation](https://github.com/naokimas/tipmoc/blob/main/delta_aicc.py)
  and [OU runner](https://github.com/naokimas/tipmoc/blob/main/run_ou.py):
  the score uses two versus four fitted parameters; the runner resets at each
  control value and collects spaced observations after equilibration. A continuous
  changing autoregression is a declared new test model, not that published run.
- [Boettiger and Hastings](https://pmc.ncbi.nlm.nih.gov/articles/PMC3427498/),
  sections 2.2 and 4: window choices and approximate stationarity affect inference;
  false alarms and missed warnings must be evaluated together. This establishes
  a standard for the experiment, not a result for TIPMOC.
- [Hallali and colleagues](https://npg.copernicus.org/articles/32/383/2025/):
  their nested Bayesian autoregression avoids fixed sliding windows and addresses
  correlated forcing. It is a different estimator, not this proposed comparison.
- [October forecast study](https://arxiv.org/html/2610.01677v1): finite-horizon
  predictions and explicit uncertainty matter to usefulness. It does not supply
  the paired TIPMOC stride comparison sought here.

## A design ambiguity worth correcting

Changing the stride changes more than dependence. With 100-sample windows,
eight estimates first exist after 800 samples at stride 100, but after 275 at
stride 25. Three successive eligible fits can first finish at 1000 and 325,
respectively. These are eligibility bounds, not predicted alarm times. Merely
reporting both arms on a common clock does not remove this difference.

Retain the published native policy as an operational comparison, but identify
its combined effects: reused measurements, earlier eligibility, more fitting,
and shorter persistence in observation time. Add one diagnostic using the same
paths and already computed fits: start both arms at sample 800, evaluate decisions
only every 100 samples, and require three consecutive common decision times.
The dense arm may still fit all variance estimates available by each time.
This diagnostic changes the native rule and must be labelled accordingly.
It asks whether extra overlapping summaries help after equalising the alarm
clock. It is not a proof that any difference has only one causal mechanism.

For an analytic sanity check, take independent Gaussian samples of variance
sigma squared. For two unbiased sample variances on windows of length L with
r shared samples, their correlation is

    (r - 2*r/L + r*r/(L*L)) / (L - 1).

Derivation: embed each centering matrix P in the common sample coordinates.
Gaussian fourth moments give covariance 2*sigma^4*trace(P_A P_B)/(L-1)^2;
the trace is r-2r/L+r^2/L^2 and each variance is 2*sigma^4/(L-1).
At L=100 and r=75 the correlation is 0.748106. Disjoint windows give zero.
This elementary calculation is not a new theorem or a model for fitted-score
dependence; temporal correlation and changing dynamics require the experiment.
An independent direct matrix-entry sum matched the trace formula in all 42
overlap cases for window lengths two through eight, using exact rational arithmetic.

## Proposed acceptance boundary

Preserve estimator admission, separately seeded calibration and held-out paths,
trajectory-level false alarms, non-detections and numerical failures. Freeze
both decision policies, timestamp convention, initialisation, horizon, optimiser
randomness, compute cap and precision target before evaluation. Report fit counts
and runtime as costs; no post-hoc extension of the budget to rescue an unclear
answer. Calibrated thresholds are empirical, not independent-sample significance
levels. No inference to an actual climate tipping date follows.

This deserves a small science slot because it could answer a named open methods
question with a checkable experiment. Its audience is specialist researchers,
not demonstrated mass demand. Reproduction failure, or uncertainty wider than
the frozen useful precision, ends the attempt honestly. The revised brief must
earn new independent keeps; this research is not its own endorsement.
