### 1. rulebook-preflight — Rulebook Preflight: catch the mismatches before a stranger plays
A zero-account offline checker for a board/card game draft rulebook as plain
text: cross-references to missing sections, defined terms never used and
capitalised terms never defined, component-list entries never mentioned again,
and player-count/setup coverage the designer declares. Human proofreading stays
the final check; this is the mechanical pass designers currently beg forum
volunteers for.

### 2. twine-variable-audit — Twine Variable Audit: find the variable that was never set
An offline checker for an existing Twine 2 HTML or Twee story that follows
links as paths and reports variables read before any set on some reachable
path, near-name pairs that differ only by case or spelling, sets never read,
and boolean/string comparison drift — with one example path per finding.
Existing tools draw the graph or follow literal links and explicitly leave
variables and conditional choices to an in-game check.
