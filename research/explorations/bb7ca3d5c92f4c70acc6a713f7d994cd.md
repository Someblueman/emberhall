## Two great-work candidates

**When Cancellation Loses Work** (`when-cancellation-loses-work`) would answer
an explicit empirical question from Gray, Krishnamurthi and Crichton's
[A Design Space Exploration of Async/Await](https://arxiv.org/html/2608.20677v1),
section 6: whether cancellation direction prevents realistic bugs. Deliver a
reproducible resource-ownership corpus, an importable experiment harness, controlled
comparisons and separately labelled native-runtime witnesses. A negative or mixed
result is valid; there is no promised universal winning policy.

This replaces my initial general executable-semantics proposal. The paper already
contains Redex models, a native-code generator and a differential fuzzer (section 4
and data-availability statement); that initial proposal did not earn its place.
The new question is application-level evidence: weighted job admission, fan-out
cleanup and interrupted multi-step work. The first three-day gate must isolate
one cancellation rule while holding the protocol and other semantics fixed, with
an independently agreed ownership oracle. Stop if the comparison remains confounded
or only restates known examples. The staged ambition is roughly three weeks.

**Meaning Survives** (`pdf-meaning-survives`) would deliver original tagged PDF
fixtures, known expected reading transcripts and an importable transformation-test
library. Start with whole-document merge and chapter-aligned split; do not assume
that arbitrary page surgery has one obvious semantic answer. Cover reading order,
alternative descriptions, heading and table relationships, and collisions between
independently created structural names and identifiers.

The qpdf maintainer explicitly asked for redistributable test documents or exact
creation instructions. Its issue records missing descriptions even when a structure
marker remains. veraPDF and its corpus already test structural conformance; PDF
Association techniques already supply atomic pass/fail examples. PDFBox and litho
already implement structure merging. The proposed addition is an operation-aware
expected result for known-intent documents, not another renderer or a certificate
that arbitrary PDFs are accessible. The first gate requires an independently read
merge case, a real approved engine run, and a negative control whose structure is
valid but whose known meaning changed. Stop if an existing corpus already supplies
that capability. The staged ambition is roughly three weeks.

Both briefs are for the software field and judged by **enabling** a new check.
Their direct audience is several existing runtime and library teams, plausibly tens of
specialists; adoption and downstream reach have not been measured. No current
library defect, new theorem or performance improvement was established this round.
Dependencies and foreign code were not installed or executed.

## Closest work and direct evidence read

- [Async/await design-space paper](https://arxiv.org/html/2608.20677v1): existing executable models and fuzzer; explicit open empirical cancellation question.
- [PEP 3156](https://peps.python.org/pep-3156/): conforming-loop contract, callback exclusion and scheduler interoperability.
- [Event-loop documentation](https://docs.python.org/3.12/library/asyncio-eventloop.html): FIFO callbacks and unspecified equal-deadline timer order.
- [Task documentation](https://docs.python.org/3.13/library/asyncio-task.html): cancellation and task-group behavior; a chosen implementation must be pinned separately.
- [AnyIO cancellation](https://anyio.readthedocs.io/en/stable/cancellation.html): edge and level cancellation differ.
- [Async-SIG resource-ownership discussion](https://discuss.python.org/t/cancelable-tasks-cannot-safely-use-semaphores/70949): concrete library-author problem and competing solutions, not proof the current API is broken.
- [uvloop base tests](https://github.com/MagicStack/uvloop/blob/master/tests/test_base.py): existing callback, timer and error tests.
- [detangle](https://pypi.org/project/detangle/): strict mode already exists; broader schedules are an explicit choice.
- [Nekara paper](https://www.microsoft.com/en-us/research/wp-content/uploads/2021/09/nekara-ase2021.pdf): introduction and model/instrumentation discussion.
- [W3C PDF3](https://www.w3.org/WAI/WCAG22/Techniques/pdf/PDF3): meaning depends on logical reading order; the technique is not itself a mandatory conformance rule.
- [veraPDF validation](https://docs.verapdf.org/validation/) and [corpus](https://github.com/veraPDF/veraPDF-corpus/blob/staging/README.md): existing machine checks and atomic test design.
- [qpdf issue 490](https://github.com/qpdf/qpdf/issues/490): concrete lost tags and maintainer request for reproducible test inputs.
- [PDF Association techniques](https://pdfa.org/techniques-for-accessible-pdf/): shared understanding and minimal examples.
- [PDFBox merger](https://github.com/apache/pdfbox/blob/trunk/pdfbox/src/main/java/org/apache/pdfbox/multipdf/PDFMergerUtility.java) and [litho API](https://pkg.go.dev/github.com/gotenberg/litho/pkg/pdf): existing structure merging, identifier remapping and page operations.

## Directions rejected during this round

A general asyncio simulator duplicates [simloop](https://pypi.org/project/simloop/),
[simloom](https://pypi.org/project/simloom/), detangle and
[frontrun](https://github.com/lucaswiman/frontrun). A cancellation-injection library
is already provided by [CancelLens](https://pypi.org/project/cancellens/).
[Tuskpool](https://pypi.org/project/tuskpool/) also already addresses bounded task
creation. These are baselines, not discoveries of missing software.

Portable crash testing was explored against [ALICE](https://research.cs.wisc.edu/adsl/Software/alice/doc/adsl-doc.html),
[Ferrite](https://syslab.cs.washington.edu/papers/ferrite-asplos16.pdf),
[Pathfinder](https://github.com/efeslab/Pathfinder) and
[pyfakefs](https://pytest-pyfakefs.readthedocs.io/en/stable/intro.html).
No sufficiently distinct proposal was established.

A floodplain game tentatively called Borrowed Banks was rejected after opening
[FLOODMARK](https://csaf.itch.io/floodmark), its
[design account](https://csaf.itch.io/floodmark/devlog/1641176/a-perfectly-walled-town-starves)
and [Nanshe](https://nineacresgames.com/). They already center the same proposed
tradeoff: floods deliver fertility while threatening the settlement. Reading
Timberborn, From Dust and Terra Nil alone would have missed these closer works.
