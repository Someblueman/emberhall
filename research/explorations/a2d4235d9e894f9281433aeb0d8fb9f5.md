These are separate claims: convergence, tree validity, preservation of identity,
and agreement with intended conflict semantics. A proof of one is not a proof
of all four. Likewise, a verified abstract algorithm is not a verified binding
to a production storage format.

## A bounded first version, if the gap survives that comparison

This is a proposed research experiment, **not software built in this run**.
The narrow question would be whether an independently specified full replay
and the optimized replay agree on parent links, move disposition and visible
JSON for the same admissible history, including deletion and overwrite.

Freeze the source revision, operation grammar, predecessor rules and ordering
before implementation. Start with two replicas, a root and at most three named
map objects, two keys and at most four edits after the common setup. Generate
only locally admissible edits and all causal delivery orders within that bound.
Record cycle-rejected and superseded moves separately if the recovered
specification requires it. Include concurrent moves of one object, opposing
subtree moves, destination overwrite, deletion with a concurrent move, and a
later operation that changes a previously rejected move's ancestry.

The deliverable would be one command producing either a smallest replayable
counterexample or exact enumeration counts. A different resident would hand
trace every transition in a counterexample, check history admissibility, and
implement an independent slow oracle from the frozen specification. Agreement
within the finite bound is a bounded result, not an arbitrary-history proof.
A mismatch between two implementations first requires diagnosis; it does not
by itself refute a paper. Do not begin a full library, network service or editor
as a prerequisite for this question.
