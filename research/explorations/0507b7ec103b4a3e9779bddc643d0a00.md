## 1. Prospective warnings of critical transitions

- [Dakos et al., 2024](https://esd.copernicus.org/articles/15/1117/2024/):
  read the comparative-analysis limitations and discussion. Different testing
  methods and significance levels obstruct comparisons; retrospective selection
  and unreported negatives are concerns. A generic comparison is not new.
- [Boettiger and Hastings, 2012](https://pmc.ncbi.nlm.nih.gov/articles/PMC3427498/):
  read the abstract and introduction. Model-based discrimination and explicit
  false-alarm versus missed-detection comparisons already exist.
- [Laitinen et al., 2021](https://pmc.ncbi.nlm.nih.gov/articles/PMC8525087/):
  read the simulation comparisons and discussion. Probabilistic autoregression,
  observation noise and bandwidth-sensitive false findings are already studied.
- [Du Plessis et al., October 2026](https://arxiv.org/html/2610.01677v1):
  read the forecasting, skill and uncertainty sections. Finite forecast horizons,
  observation processing, calibration and model discrepancy are explicit parts
  of the present programme, not omissions we can simply announce.
- [Helmich et al., 2024](https://www.ppw.kuleuven.be/okp/_pdf/Helmich2024SDABC.pdf):
  read the prospective-monitoring discussion, especially page 9. Repeated tests
  create a different false-alarm problem from a single retrospective test. This
  establishes a methodological concern in psychology, not validation of a
  climate alarm or permission to claim a clinical application.
- [TransitionsInTimeseries.jl](https://github.com/JuliaDynamics/TransitionsInTimeseries.jl):
  read the repository description and extension interface. Existing pipelines
  already accommodate indicators and significance tests. Did not run it.
- [BenchEWS publications](https://research.vonmallinckrodt.com/publications):
  opened the author's publication index as an overlap lead, not as independently
  validated evidence that a particular benchmark guarantee holds.

Possible remaining question: a narrowly specified prospective alarm with a
trajectory-level false-alarm guarantee under declared dependent-noise assumptions.
I did not establish a novel method, useful detection-power target, or advantage
over existing sequential monitoring. Do not repackage familiar false-positive
examples as a weeks-long scientific result.

## 2. What partial observations can establish about dissipation

- [Fritz, Ertel and Seifert](https://arxiv.org/html/2412.04102v2): read the
  abstract and conclusion plus model discussion. Finite statistics can make
  empirical estimates exceed the true entropy production. Their concluding
  request for quantifying overestimation is a real research lead. Their existing
  four-state and enzyme examples already compare resolution/statistics tradeoffs.
- [Dieball and Godec](https://arxiv.org/html/2412.02675v3): read the coarse-graining
  and outlook sections. Instantaneous observation and history-dependent
  milestoning have different time-reversal contracts. A positive statistic need
  not establish physical dissipation when those assumptions are wrong.
- [van der Meer et al., 2022](https://doi.org/10.1103/PhysRevX.12.031025):
  opened the primary journal account of transition-based waiting-time inference.
- [Fritz and Seifert, September 2026](https://journals.aps.org/pre/abstract/10.1103/zj2b-w93z):
  read the abstract. A newer estimator treats continuous space without Markovian
  events; do not claim that all existing methods require those events.
- [SFI reference](https://stochasticforceinference.readthedocs.io/en/latest/inference/reference.html):
  read the entropy-production estimator and uncertainty entries. Existing
  software already reports fluctuation bias, debiasing and error estimates for
  its stated observation/model contract. Did not download or execute it.
- [Bhandari, August 2026](https://arxiv.org/abs/2608.13431): read the abstract,
  which claims bias removal, block errors and a test under a stated block null.
  This is a competing inference lead, not a theorem independently checked here.

Possible remaining question: finite-sample lower confidence bounds for a fixed
resolved-transition observation contract. I did not prove such a bound, establish
its novelty against newer inference methods, or show that a useful nonzero bound
is attainable at a practical observation length. Generic estimator comparison
alone would repeat the first paper. This is the strongest unfinished lead.

## 3. Biological models and causal interaction recovery

- [Barraquand et al.](https://arxiv.org/html/1909.00731v3): read the introduction
  and scope. Comparisons of Granger causality and convergent cross mapping already
  include stochastic/deterministic competition, shared drivers and larger
  ecological networks. Merely comparing those methods is not a new project.
- [Neubrand et al., October 2026](https://pmc.ncbi.nlm.nih.gov/articles/PMC13712306/):
  read the abstract and introduction. Their 1,100 synthetic problems include
  experimental conditions, observation functions and varying identifiability.
- [Their released collection](https://github.com/niklasneubrand/1100SyntheticBenchmarksODE):
  opened the repository. It is an extension of Data2Dynamics; I did not run it
  or verify all released problems. A new generic model-benchmark collection needs
  a specific missing regime, not just an older call for more benchmarks.
