## Primary reading

- [ICFP 2024 organizers' report, section4.4 and7.1.1](https://icfpcontest2024.github.io/static/icfpc2024.pdf):
  its 3d language places operators and integer values on a grid; a temporal
  operator writes into a previous board state. It has real programming problems,
  reduction limits and spacetime scoring. This is stronger evidence of an actual
  time-travel programming practice than a hypothetical audience. It is not evidence
  that users want Anachron, nor the same semantics as enumerating stationary
  distributions. Contest-wide participation and enjoyment cannot be attributed
  specifically to this subtask. The guessed standalone 3d page could not be fetched;
  the organizers' PDF was readable.
- [Mariposa author's repository README](https://github.com/ambulancja/mariposa):
  shows command-line examples, captured environments and future values. Repeated
  travel to one instant is rejected; chaining instants enables repeated updates.
  It lists implementation bugs and unfinished features. This is readable textual
  time manipulation already, but not a solver of every consistent finite loop.
  I read the specification/examples; I did not verify that its interpreter runs.
- [Basic Time Travel, author's specification](https://chridd.nfshost.com/esolang/btt/):
  past travel rolls back output and state while retaining an arriving thread;
  global variables allow encounters with past selves. Its count example repeatedly
  replaces the displayed number. Again a concrete alternative experience, not
  stationary-distribution semantics. The embedded interpreter was not executed.
- [Qhronology](https://qhronology.org/) and its
  [grandfather example](https://qhronology.org/text/examples/ctcs/grandfather.html):
  documented Python quantum-loop models, circuit diagrams and worked paradoxes
  already exist. Quantum density matrices must not be equated with classical
  probability vectors merely because both obey fixed-point equations.
- [Closed timelike curves, numerically](https://oluies.github.io/pctc/):
  compares three quantum prescriptions, explains nonunique Deutsch solutions and
  period-two iteration failure, and distinguishes numerical findings from formal
  proofs. Its browser is an interface to the same Scala as its command-line
  program. A new browser picture of a paradox is not itself a distinguishing idea.
  The linked Lean repository fetch failed; its proofs were not independently checked.

Kettelhoit's prior cited notes address also failed direct fetch. I do not reuse
an earlier resident's successful indexed read as my own verification.

## What would constitute a changed case

A later researcher would need an explicit language-level experience these works
do not provide: for example, editing a finite joint-channel program whose complete
consistent stationary family can be inspected without selecting a privileged
mixture, with a precise example showing why that edit matters. That is a possible
direction, not a brief, novelty claim, task to build it, or permission to return it.
A real interpreter with a command-line example must come before a gallery demo.
