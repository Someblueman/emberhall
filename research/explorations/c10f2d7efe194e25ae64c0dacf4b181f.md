## Need and proposed contribution

Neural timescale estimates describe how long activity persists. Existing
multistep regression corrects spatial undersampling, under explicit assumptions
about independent observation errors. A detector whose sensitivity stays high
or low for successive time bins violates that independence even when its
long-run distribution is stationary. The proposed small study asks whether the
published estimator diagnostics reject such recordings or accept misleading
timescales. It would deliver a reproducible scientific report and simulation,
not another estimator package or a web demonstration.

The practical contribution must be an error-and-rejection boundary under a
specified observation model, beyond restating the known independence caveat.
An independent resident must first verify that the original estimator and its
diagnostics have been reproduced. No claim about actual brain recordings follows
from this synthetic experiment.

## Primary reading and alternatives

1. [Wilting and Priesemann, 2018, including supplement](https://arxiv.org/html/1608.07035v3):
   Definition S1(i) explicitly requires conditional independence between sampling
   times. Supplement 5 and Table S1 specify five diagnostic tests. These are part
   of the baseline, not checks to omit because they might reject the data.
2. [Spitzner et al., 2021](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0249447):
   the existing toolbox supplies plain and offset exponential fits, two ways of
   pooling trials, and a branching-process example with a known timescale.
3. [de Heuvel et al., 2020](https://arxiv.org/html/2005.00608v1):
   corrects repeated changes in external input. Changing the hidden activity's
   drive is a different mechanism from correlated detection of unchanged activity.
4. [Garcia et al., 2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC10897502/):
   benchmarks drift correction and finds remaining spike-sorting limitations.
   This motivates examining observation errors; it does not validate our proposed
   two-state detection model as a measured model of drift.
5. [Pochinok et al., 2026](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1013385):
   iSTTC addresses sparse and epoched single-unit recordings. Its discussion
   distinguishes synthetic ground truth from real-data robustness. It is not
   interchangeable with a population-count branching estimator.
6. [IntrinsicTimescales.jl tutorial](https://duodenum96.github.io/IntrinsicTimescales.jl/dev/practice/practice_5_bayesian/):
   explicitly marked gaps and model-based inference already have implementations.
   Silent loss of some spikes is different from a known missing-data mask.
7. [Multi-timescale switching model, 2026 preprint](https://arxiv.org/html/2610.01786v1):
   models richer latent dynamics; its fixed-regime covariance derivation uses
   white observation noise. This is relevant context, not a promised comparison
   against every neural-timescale method.
8. [Zeraati et al., review, 2026 author version](https://arxiv.org/html/2409.02684v3):
   section 2.1 explicitly distinguishes underlying neural differences from
   measurement constraints. This is a stronger field standard for the proposal
   than a generic statement that recording methods have limitations.

## Minimum experiment if selected

Use a stationary, driven count process with known persistence. Observe each
count through binomial detection with a separate stationary two-state detection
probability. Compare correlated detection, independent detection with the same
probability distribution, and constant detection with the same mean. Pair latent
paths and report realized retained counts; do not claim exact count equality.
Include independent Poisson activity as a zero-persistence control, and keep
the true time axis. A control supplied with the actual detection probabilities
can separate loss of information from a mistake in the generator.

First derive the positive-lag covariance under this observation model; this is
a proposed mechanism check, not a completed theorem. Then freeze simulation
cells, fit bounds, diagnostic thresholds, seeds, precision target and compute
cap before evaluation. Measure accepted-but-wrong estimates, rejection rates,
fit failures and uncertainty across independent trajectories. Report errors
among accepted fits alongside their unconditional frequency so rejection cannot
manufacture apparent accuracy. Preserve unsuccessful and inconclusive cells.

Acceptance requires a checked analytic mechanism plus a finite-data result that
actually answers the diagnostic question. Stop if baseline reproduction fails,
or if the bounded experiment adds only the known caveat without a useful error
or robustness boundary. No code downloaded from the web was run. NumPy and SciPy
were available in the current interpreter; nothing was installed.
