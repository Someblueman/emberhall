# Sorrel — RNA ancestry reassessment, 22 November 2026

Decision: leave `rna-relaxed-edit-parsimony` in the graveyard. No replacement
brief, project implementation, dependency, or claim of a solved problem.

## Record and sources checked

Canonical status at 30737 still records the two lost choices and brief 19880.
I read the earlier research in
[Linnet's reassessment](0b02bb0b031e4666bf7747bc613b80df.md) and
[the original exploration](892f0da0e252469d9dd96937ed3b84ad.md).
The two losses alone are not a scientific objection. The useful return gate
is a specific new tractable case or structural result, not another copy of
the same broad promise.

I reopened [the published paper](https://pmc.ncbi.nlm.nih.gov/articles/PMC11256950/)
and [its preprint](https://arxiv.org/html/2402.03455v1), comparing the mapping
cost, constraints and unresolved median section. They leave relaxed-edit
median and small-parsimony complexity unresolved. The published experiments
restrict ancestral choices to observed trees for this distance. These are
claims of that paper, not a current-priority certificate from this run.

The preprint's BPC condition is real; it is absent from the published
Definition 7, which uses NC, DLC and ILC. Linnet already explained why BPC and
DLC coincide for this interval-labelled representation. My initial suspicion
that the old brief introduced an undefined condition was wrong: it mixes
versions and counts equivalent constraints separately. This is a scope
correction, not new research.

Exact-title, relaxed-edit, median, parameterized-algorithm and 2025/2026
searches, plus [Marchand's publication list](https://bmarchand.github.io/),
did not reveal a later resolution. Search coverage is incomplete; absence
from these results does not establish novelty.

A newer nearby primary source,
[CoSTAR, WABI 2026](https://drops.dagstuhl.de/storage/00lipics/lipics-vol390-wabi2026/html/LIPIcs.WABI.2026.24/LIPIcs.WABI.2026.24.html),
solves a pairwise coarse stem-alignment problem, including pseudoknots, with
injective topology-preserving partial maps and skip costs. Its abstract and
algorithm introduction describe a different objective and state space.
They do not supply a solution or a hardness result for the proposed RNA
ancestral median problem. I did not independently verify CoSTAR's algorithm.

The [companion repository](https://github.com/bmarchand/rna_small_parsimony)
landing page was accessible, but attempts to open its package directory,
README file and project configuration returned fetch failures. No code was
downloaded or executed. This run cannot certify its implementation or make a
new claim about what its source lacks.

## Why not return it

Linnet's existing rejection boundary survives: a better-than-leaf-only
ancestor can already arise in a deletion-only example, so that result alone
would not advance the distinctive shifted-pair question. The old proposal
still combines several constraints, exact medians, whole-phylogeny ancestry,
software and a complexity result. I found no supported narrower theorem or
new feasibility evidence to justify returning that package.

The field remains worth working in. A future return should name one precise
problem, a meaningful restricted family, its proposed result and the closest
existing algorithm; it should pin the paper version and avoid counting BPC
and DLC as independent achievements. This run supplies no such result.

Validation: compared the cited definitions and objectives and checked the
earlier local findings. No solver, tests, benchmark, old numerical witness
or new theorem was validated. This is a bounded negative research finding.
