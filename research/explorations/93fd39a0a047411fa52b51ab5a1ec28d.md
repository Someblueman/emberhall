## Selected idea: `mote-error-provenance-lang`

**Mote: A Numerical Language with Built-In Rounding Provenance** (`scale: "small"`, `field: "language"`, `worth: "enabling"`, `for: "field"`).

### Why the field gap is concrete

- **Fluctuat** (`https://www.lix.polytechnique.fr/Labo/Sylvie.Putot/fluctuat.html` and NASA Langley `https://ntrs.nasa.gov/api/citations/20230011807/downloads/VSCode-PRECiSA%20-%20A%20Toolkit%20for%20Floating-Point%20Round-Off%20Error%20Analysis.pdf`): uses a zonotopic abstract domain to bound rounding errors across loops (`widening`), treat unstable tests, and decompose error along source provenance — **but is commercial / closed-source**.
- **Daisy** (`https://github.com/malyzajko/daisy`, `https://arxiv.org/abs/1707.02118`): open-source (Java 22–25, C compiler, MPFR, Z3/dReal), focuses on straight-line arithmetic kernels (`"In this work, we focus on arithmetic kernels, and do not consider conditionals and loops."`).
- **Satire** (`https://arxiv.org/abs/2503.05924`, `https://github.com/arnabd88/Satire`): scalable global-optimization bounds explicitly restricted to straight-line loop-free programs (`"It works on straight line floating-point programs."`).
- **PRECiSA & ReFlow** (`https://github.com/nasa/PRECiSA`, `https://github.com/nasa/ReFlow`): computes sound bounds, supports bounded `for`-loops, and instruments C code for unstable tests, **requiring PVS, Kodiak, and Frama-C** and not producing per-line error-provenance shares.
- **FPTaylor** (`https://github.com/soarlab/FPTaylor`): symbolic Taylor optimization for loop-free expressions.
- **Herbgrind** (`https://arxiv.org/abs/1705.10416`, `https://github.com/uwplse/herbgrind`): dynamic Valgrind binary analyzer on single concrete executions, not static interval boxes.

Mote unifies static outward-rounded zonotopes (`math.nextafter`), Fluctuat-style per-line error provenance across conditionals and bounded/invariant loops, unstable-branch diagnostics, native `compare A vs B` formulation blocks, and concrete IEEE-754 witnesses checked against 80-digit `Decimal` in a single zero-dependency Python 3.10+ CLI.
