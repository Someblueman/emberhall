# Isothermal fixation: narrow the result, not just the search

Hawthorn, 18 November 2026. Research for the shelved `isothermal-reducers`
idea. This is an unreviewed mathematical sketch and a proposed research
boundary, not an accepted theorem, a selected project, or a new solver.

## Finding

The two questions in the existing brief really appear in the 2020 paper.
However, a large catalogue of sampled graphs and fitness values cannot answer
either universal question. High precision does not turn those samples into a
certificate. The first version should seek a complete result on a specified
continuous family, with an explicit failure condition, before attempting both
update rules and many unrelated graph families.

There is a concrete starting point: the four-vertex weighted isothermal case
reduces to at most five transient symmetry classes and a concavity inequality. I derive
it below. It is a calibration result, not enough by itself to justify a project.
A worthwhile bounded target would settle the corresponding inequality for
**every connected weighted isothermal graph on five vertices**, or exhibit a
certified counterexample. Merely recovering the four-vertex argument below,
the known cycle formula, or a sampled five-vertex table would fail acceptance.
Its novelty must still be checked before and during a selected attempt.

The existing Birth-death question should be deferred. For this first version,
Birth-death on isothermal graphs is a known equality control, not a second
research programme. Complete graphs are also equality cases for death-Birth:
the proposed statement is non-increase, with equality characterized separately,
not strict reduction on every isothermal graph.

## Four vertices: a reconstructible research seed

Fix a connected undirected graph on four labelled vertices, with nonnegative
edge weights, no loops and equal positive weighted degree. Scale that degree
to one. Solving the four row-sum equations gives opposite edges equal:

```
W = [ 0 a b c ]
    [ a 0 c b ]
    [ b c 0 a ]
    [ c b a 0 ],       a+b+c=1.
```

At least two of a,b,c must be positive for connectivity. The permutations
that preserve this matrix act transitively on the vertices. There are at most five
transient classes: a singleton, its three-vertex complement, and a pair for
each of the three internal edge weights. Let their eventual all-mutant
probabilities be U, V and Z_t, for t in {a,b,c}. Mutant fitness is r>0;
resident fitness is one. Each update kills a uniformly chosen vertex and
chooses its replacement parent proportionally to fitness times edge weight.

Set

```
d_t = r*t / (1+(r-1)*t)
e_t =   t / (r+(1-r)*t)
A = sum(d_t), B = sum(e_t).
```

A singleton disappears with probability 1/4. It becomes the pair with
internal weight t with probability d_t/4. A three-mutant state fixes with
probability 1/4 and loses a mutant to the pair of type t with probability
e_t/4. A pair grows or shrinks with respective probabilities

```
p_t = r*(1-t) / (2*(r+(1-r)*t))
q_t =   (1-t) / (2*(1+(r-1)*t)).
```

The shared factor 1-t is positive for a connected graph. Thus

```
Z_t = alpha_t*V + (1-alpha_t)*U
alpha_t = r*(1+(r-1)*t) / (2*r+(r-1)^2*t).
```

The singleton and three-mutant harmonic equations become

```
(1+A)*U = sum(d_t*Z_t)
(1+B)*V = 1+sum(e_t*Z_t).
```

Write S=sum(t/(2*r+(r-1)^2*t)). The identities
d_t*alpha_t=r^2*t/(2*r+(r-1)^2*t) and
e_t*(1-alpha_t)=t/(2*r+(r-1)^2*t) reduce these to
U=r^2*S*(V-U), V=1-S*(V-U). Consequently

```
rho_W(r) = U = r^2*S / (1+(r^2+1)*S).
```

For r different from one, f(t)=t/(2*r+(r-1)^2*t) is strictly concave on
the nonnegative interval. Its second derivative is

```
f''(t) = -4*r*(r-1)^2 / (2*r+(r-1)^2*t)^3.
```

Jensen's inequality therefore gives S<=3/(r^2+4*r+1), with equality
only when a=b=c=1/3. The expression for U is increasing in S. Substitution
gives U<=3*r^2/(4*(r^2+r+1)), the loop-free complete-graph probability.
At r=1, U=1/4 directly. Zero-weight boundaries remain covered when connected;
the disconnected perfect-matching vertices are excluded.

This sketch has not been independently reviewed. A selected project must
reconstruct the stochastic equations, absorption justification and equality
conditions without trusting this derivation.

## Checks performed in this research run

Locally authored, disposable SymPy calculations checked the two elimination
identities, the complete-graph substitution and the displayed second
derivative exactly. A separate direct 14-state harmonic solve agreed exactly
with U for five weight triples, each at r=1/2,1,3/2,2:

```
(1/3,1/3,1/3), (1/2,1/2,0), (1/6,1/3,1/2),
(1/20,3/20,4/5), (0,1/5,4/5).
```

All twenty rational comparisons agreed and satisfied the complete-graph
bound. These finite checks support transcription; they do not establish the
universal inequality, novelty, a five-node result, or independent acceptance.
No code was downloaded, no dependency installed, and no project implementation
was built. The proposed delivered checker would be a separate, reviewed
standard-library program only after selection.

## Proposed acceptance boundary

Seek an exact proof or counterexample for all connected symmetric, loop-free,
row-sum-one five-by-five weight matrices, for every r>0, with uniform initial
placement. A proof must cover the continuous weight domain and its connected
boundary faces, justify denominator signs and absorption, and characterize
equality. A counterexample needs rational weights and a rational fitness value
whose strictly larger fixation probability can be independently checked.

For five vertices, Friedland's characterization gives twelve labelled
five-cycle extreme points (edge weights one half) and ten triangle-plus-edge
extreme points (triangle weights one half, matching edge weight one). These
counts follow from 5!/(2*5) and choosing the three triangle vertices. The
latter ten graphs are disconnected. The full convex hull has five independent
edge-weight coordinates. This is a possible exact parameterization, but
checking its vertices alone proves nothing about the nonlinear fixation
probability in the interior. No general convexity claim has been established
here, and disconnected vertices cannot be assigned an absorbing-chain inverse
as though connected. Those are concrete obstacles for the proposed attempt.

The first completed object is a mathematical note with small exact
certificates and one command to check them. A graph census, a derivative at
neutrality, floating-point confidence, or an unverified computer-algebra
assertion is not that object. Stop if prior work already supplies the result,
if the argument only covers the four-node calibration, or if the five-node
claim cannot be established in the allotted small-project time. A failed
attempt should preserve its precise obstruction rather than grow into an
indefinite catalogue.
