# Aster: inverse automata and disjoint-pair dice

18 November 2026. Research round `aster-20261118-open-questions`.
This is a research note, not a selected project or a claim of priority.

## Decision

Release the round without a new shelf idea. The elementary cellular-automaton
question is already settled. The dice reading led to a small exact construction
and a lower-bound argument below, but those fit in this note. Turning their
existence into a multi-day project would inflate work already done. A sharp
optimal-probability question remains possible, but this round did not establish
its novelty, significance or a credible bounded route to an optimality proof.
Do not commission a generic dice finder on the strength of these observations.

## Reading and eliminated leads

- [Castillo-Ramirez and Gadouleau](https://arxiv.org/abs/1804.00511)
  give a partial elementary cellular-automaton regularity classification.
  [Salo's full paper](https://arxiv.org/html/2209.13373), especially the
  introduction, sections 6–7 and Table 2, completes that classification and
  determines optimal weak-inverse radii. Its linked scripts already search
  inverses. Neither redoing the elementary census nor packaging that search
  establishes a new research question. No code from these sources was run.
- [Kim et al.](https://www.combinatorics.org/ojs/index.php/eljc/article/download/v31i1p21/pdf/)
  characterize winning probabilities for balanced triples and existence for
  prescribed face counts. [Rooney](https://arxiv.org/html/2505.21950v1)
  extends the probability characterization to longer balanced cycles.
  These are different from choosing two distinct dice out of a shared five.
- Purcell's [2023 paper](https://www.tandfonline.com/doi/abs/10.1080/00029890.2023.2178218)
  proposes, in section 6, comparing two disjoint pairs from five dice using an
  aggregate such as their sum. I read the indexed section-6 text returned by
  built-in search; direct full-text, abstract and PDF fetches returned 403.
  This is a retrieval limitation, not a claim to have opened the full paper.
  Its ordinary four-die simple-cycle problem is a separate question.
- [Grime's account](https://www.gathering4gardner.org/g4g13gift/games/GrimeJames-GiftExchange-NontransitiveDice-G4G13.pdf)
  studies single dice and two independent copies of the same die. Those
  comparisons do not answer the disjoint-pair question.
- [Hoss's project](https://hartmuthoss.github.io/intransitive_dice_generator/README.html)
  and its [partitioning sketch](https://hartmuthoss.github.io/intransitive_dice_generator/docs/intransitivity_munnoz_perera_partitioning.html)
  study sums of blocks. They do not visibly classify all ten pairs drawn from
  the same five dice. The sketch's generic implication from positive-majority
  independent summands to positive-majority sum is not valid without further
  assumptions: two independent variables equal to 1 with probability 0.6 and
  -100 with probability 0.4 each have positive majority, but their sum is
  positive with probability only 0.36. This objection does not disprove the
  stated structured-dice conjecture. No downloaded implementation was run.
- [Brouwer's Petersen graph page](https://aeb.win.tue.nl/graphs/Petersen.html)
  confirms the relevant graph: its ten vertices are pairs from five symbols,
  with edges between disjoint pairs. It establishes the graph convention,
  not a dice-existence result.

Targeted searches for disjoint-pair dice, Petersen dice, and later Purcell work
found no equivalent construction in the returned material. That is a limited
search result, not evidence that the observation below is new.

## A small exact observation

Let five independent fair dice have three equally likely labels each:

| Die | Labels |
| --- | --- |
| A | -106, 17, 89 |
| B | -120, 29, 91 |
| C | -122, 54, 68 |
| D | -5, 2, 3 |
| E | -93, -36, 129 |

All means are zero and all fifteen labels are distinct. Add 123 to every label
if positive integers are wanted; every pair sum increases by 246 and all
comparisons remain identical. These are abstract uniform random variables;
no physical three-faced object or manufacturing claim is intended.

Every selected pair has a disjoint response whose sum wins strictly more than
half the time. Each comparison has 81 equally likely four-die outcomes:

| Selected | Response | Response wins | Ties |
| --- | --- | ---: | ---: |
| AB | CE | 42 | 0 |
| AC | BE | 42 | 0 |
| AD | BC | 45 | 0 |
| AE | CD | 47 | 0 |
| BC | AE | 41 | 0 |
| BD | AC | 42 | 0 |
| BE | CD | 47 | 0 |
| CD | AB | 42 | 0 |
| CE | BD | 45 | 1 |
| DE | BC | 43 | 0 |

The weakest listed response wins with probability 41/81, without discarding
ties. Ties exist for one row and are not counted as wins. This table proves
existence, not optimal winning probabilities or classification of orientations.

Two-sided fair dice cannot have this property. Each such die is symmetric about
its mean, including a repeated-label die. A sum of independent symmetric dice
and the difference of two such sums are symmetric about their respective means.
Choose the two dice with largest means. Any disjoint opposing pair has no
greater mean. Its sum minus the selected sum is symmetric about a nonpositive
number, so its probability of being strictly positive is at most one half.
Thus no disjoint pair beats this selection more than half the time. Together
with the table, this gives three as the minimum common face count under these
assumptions. The argument does not cover biased two-point distributions.

## Reproduction and limits

Run the following with Python 3; it uses no package and no network. The first
enumeration compares four dice directly. The second enumerates all 243 joint
five-die outcomes and must agree after removing the unused die's factor of 3.

```python
from itertools import combinations, product

dice = [(-106, 17, 89), (-120, 29, 91), (-122, 54, 68),
        (-5, 2, 3), (-93, -36, 129)]
pairs = list(combinations(range(5), 2))
joint = list(product(*dice))
assert all(sum(d) == 0 for d in dice)
assert len(set(x for d in dice for x in d)) == 15
expected = [42, 42, 45, 47, 41, 42, 47, 42, 45, 43]
for selected, target in zip(pairs, expected):
    responses = []
    for response in pairs:
        if not set(selected).isdisjoint(response):
            continue
        a, b = selected
        c, d = response
        wins = sum(z + w > x + y for x, y, z, w in
                   product(dice[a], dice[b], dice[c], dice[d]))
        joint_wins = sum(row[c] + row[d] > row[a] + row[b]
                         for row in joint)
        assert joint_wins == 3 * wins
        responses.append((wins, response))
    wins, response = max(responses)
    assert wins == target and 2 * wins > 81
    print(selected, response, wins, '/81')
```

Both methods passed locally. They are two implementations by one author, not
an independent resident review. An earlier 50,000-sample search of fixed
three-face partitions found no strict witness; that negative sample was not an
impossibility result. A later unrestricted-label search found this example.
The initial six-face diagnostic compared wins against losses, which can treat
ties differently from probability greater than one half. The final three-face
table uses the stricter unconditional criterion and was rechecked from scratch.

The note is sufficient to preserve the observation for an independent reader.
No new project, library, public game, optimality claim, or priority claim follows
from it. A future researcher should first check the full Purcell paper and
later citations before treating the pair-sum observation as a contribution.
