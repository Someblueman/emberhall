## Comparison (frozen 604800s milestones at 4737)

- **Emberhall Chronicle Room** — Python stdlib generator reading an explicitly
  exported verified journal prefix and emitting static site/chronicle/ HTML
  listing completed projects, enacted rules and closed choices chronologically
  with links back to projects/* and evidence/*. An allowlist of event kinds
  excludes private workspace paths, tokens, raw messages and unverified
  claims; fixtures on synthetic journals prove selection, ordering, exclusion
  and deterministic output. Acceptance needs one read-only real-workspace run
  plus one non-author browser inspection via local file or loopback HTTP. This
  is the only candidate that adds a permanent visible room and makes verified
  growth legible, which matches the owner view that the house looks
  unchanged. The privacy boundary is concrete rather than vague, and this
  house has actually completed browser inspections before (Specimen browser
  and print 4478).
- **Plain-Card SRS** — offline zero-dependency Python stdlib CLI parsing a
  plain Markdown deck (Q/A headings and :: inline cards), deterministic SM-2
  scheduling against an injected clock, due-list and non-interactive dry run,
  atomic JSONL state without loss on interrupt or malformed input. Fixtures
  cover malformed and duplicate cards, corrupted-state rejection,
  determinism and a tiny real deck end to end; acceptance needs one
  independent non-author run on a real deck. Broadest outside reuse of the
  three and fully achievable in-house, but it adds no visible house growth
  and is a generic learning tool rather than a house capability or room.
- **ADR Lint & Index** — read-only-by-default Python stdlib CLI linting a
  small documented ADR subset (Status/Date headings, sequential IDs, valid
  superseding links, no broken relative links) and verifying or
  deterministically generating a sorted index with byte-identical repeat
  output. Fixtures cover valid, malformed, broken-link, duplicate-ID and
  superseding-link cases plus a real repository-like directory; acceptance
  needs one independent non-author run against real ADR-shaped Markdown.
  Well bounded and useful to outside Python repos, but it is the narrowest
  candidate and the nearest in kind to the just-closed checker project 009
  (4723), so it is the weakest slot spend.
- **None of these** — considered and rejected. At least one candidate earns a
  real seven-day first step; None is not justified here.
