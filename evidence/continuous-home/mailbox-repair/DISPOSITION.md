# The native sandbox was right

Rowan (Codex) and Asha (Muse) overlapped in real native runs, produced useful
Blackout reports, and could not write the canonical journal. Neither arrival
was accepted. Their zero process exits did not establish successful residency.
The prior direct client crossed the private-room write boundary.

The repair gives each room atomic bounded request/reply files. The coordinator
binds identity and artifact root to its accepted run, preserves the first exact
request privately, and replays lost replies without duplicating a mutation or
resnapshotting finished artifacts. Malformed files, FIFOs, symlinks, oversize
messages, stale runs and actor/root overrides fail without corrupting the record.
Quiet waits persist deadlines and reuse verified state while the ref is unchanged.

Witness also built a serialized durable action worker for council, independently
reviewed source integration and later-wake runtime tests/refresh. It imports only
the pinned archive using isolated Python. Candidate tests execute in a separate
macOS sandbox with room/scratch writes and no network. Killing the worker during
actual sandboxed testing leaves a tagged child group that recovery can stop;
unknown process groups are never signalled. A stopped requester does not keep a
slot. Unknown interrupted publications remain inspectable, not silently retried.

Independent Breaker found that OpenCode's fixed shell prefix still allowed output
redirection. Bash is now denied entirely. The private house_journal tool uses
execFile, shell:false, fixed isolated Python and the pinned mailbox implementation.
A real Node invocation verified that shell metacharacters remain literal and
workspace modules cannot shadow the trusted imports. Installed OpenCode debug
confirmed the intended tools and isolated configuration with existing auth data.

Native success no longer drops unresolved help. Assigned route identity cannot
be relabelled. A concurrent short failure cannot shorten a longer quota cooldown.
Absurd/nonfinite usage counters cannot strand a run. Stable GitHub repository
identity keeps the owner bell valid after its rename; old journal bindings remain.
All255 then-current events projected exactly like the previous committed reader.

Host acceptance and candidate acceptance are distinct. macOS forbids nested
sandboxes and execution of setuid /bin/ps inside this restrictive test sandbox.
Those host-only fixtures are explicitly skipped in candidate acceptance and run
on the host separately; the sandbox is never weakened to make them pass. The
failed candidate run is retained. Protected runtime hashes prevent later prompt
changes from changing the process/sandbox enforcement tested on the host.

Actual all-kind native reruns and installed continuous service are subsequent
acceptance steps, not claims made by these inert subprocess tests.
